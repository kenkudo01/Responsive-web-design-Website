About Me

CS Student & Systems-Oriented Software Engineer

Who I Am

I am a Computer Science student at Eötvös Loránd University (ELTE), focusing on systems and software engineering. I am particularly interested in how design decisions affect system reliability, performance, and security.

My Skills

My work spans compiler construction, concurrent and distributed systems, and architecture-level refactoring. I also develop practical software extensions, including Revit API plugins, using languages such as C++, Java, Python, and C#.

My Interests

I am deeply interested in understanding how systems fail, how vulnerabilities emerge from design choices, and how secure, maintainable systems can be built. Currently, I am expanding my knowledge in security engineering, cloud infrastructure, and SRE practices.

3D Rendering Pipeline

Custom Graphics Engine from Scratch

A purely code-based implementation of a 3D graphics rendering pipeline. Instead of using existing game engines, I built the pipeline from scratch to understand the mathematics behind computer graphics.

Technical Highlights
  • Implementation of matrix transformations (Translation, Rotation, Projection).
  • Rasterization algorithms and Z-buffering.
  • Deep usage of Linear Algebra and optimization for real-time rendering.
  • Category: Computer Graphics / Algorithms
  • Tech Stack: Java, Linear Algebra
